# 부산 시민 AI 체험의 날

부산 시민 AI 체험의 날 행사 홍보 웹페이지입니다.

- `index.html`: 홍보 웹페이지. HTML, CSS, 부산광역시 로고 및 부기 이미지가 모두 포함되어 있습니다.
- `.nojekyll`: 정적 HTML을 그대로 제공하기 위한 GitHub Pages 설정 파일입니다.

제공되지 않은 행사 정보는 “미정”으로 표시합니다.

## GitHub Pages 배포 설정

저장소 이름: `busan-event-webpage`

Settings → Pages → Build and deployment에서 다음과 같이 설정합니다.

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

## 이미지 출처

- 부산광역시 공식 로고: https://www.busan.go.kr/bhorgsymbol01
- 부산시 소통 캐릭터 부기: https://www.busan.go.kr/character
- 부기 이용 조건: 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지).
